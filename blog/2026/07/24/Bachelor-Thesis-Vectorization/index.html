Vectorizaion, in the context of compilers and High Performance Computing, refers to the transformation of scalar instructions into Single Instruction Multiple Data (SIMD) instructions, allowing the utilization of vector processors. On a higher abstraction-level, vectorization refers to the transformation of the algorithm, i.e the nested loop structure, in order to perform parallel computation.

An example of such an algorithm is the direct convolution. It is one way to compute the convolutional operation of the convolutional neural network.

How do we optimize the direct convolution algorithm?

Step one: Increase compute intensity.

Compute intensity can be increased by doing work in parallel. Here, we utilize the vector processing ability of the RISC-V vector extension.

Step two: Decrease memory accesses.

Memory accesses encompass the STORE and LOAD operations done while the algorithm is computing. This optimization requires the tiling concept. Tiling refers to changing the order of the output computation in order to utilize local memory. That is, the reuse of already loaded data amortizes the cost of memory instructions. This is, again, a consequence of the concrete memory setup of our hardware.

In the context of a scratchpad memory; the memory hierarchy only consists of a fast cache-like on-chip memory, the scratchpad, and the registers; and the main memory.

The direct convolution, when doing inference, refers to the six nested loops iterating through the output tensor dimensions while accessing the input tensor and the weight tensor.
